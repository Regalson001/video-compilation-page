# 🎥 Video Compilation Page

A sleek, accessible, and structured video compilation web page built with semantic HTML5 and embedded `<iframe>` elements. This project showcases video tutorials on core web development topics including HTML, CSS, and JavaScript.

---

## ✨ Features

- **Semantic HTML5 Architecture:** Utilizes `<main>`, `<section>`, `<h1>`, and `<h2>` elements for proper structural hierarchy and clean document flow.
- **Embedded Media Player:** Integrates responsive YouTube video embeds using native HTML `<iframe>` tags.
- **Accessibility Ready:** Includes descriptive `title` attributes on all embedded frames to ensure screen reader compatibility and Web Content Accessibility Guidelines (WCAG) compliance.
- **Structured Content Layout:** Organized sections featuring dedicated headings, introduced descriptions, and aligned video displays.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic markup and iframe embedding.
- **Git & GitHub:** Version control and source code management.
